# Lioness Enterprise Coconut — Premium E-commerce Website

A fast, responsive static storefront prepared for Vercel deployment.

## Included
- Premium Coconut White / Deep Brown / Coconut Green / Gold visual system
- Responsive home, story, products, shop, reviews, FAQ, contact, features and admin-preview sections
- Working front-end cart with localStorage
- Wishlist buttons, product search, quantity controls, newsletter/contact demo forms
- Dark/light mode
- Google Maps embed
- WhatsApp CTA
- SEO metadata and keywords
- Founder + web designer photos and Lioness Coconut logo supplied by the client
- Product imagery via remote Unsplash image URLs

## Deploy on Vercel
1. Push this folder to a GitHub repository.
2. In Vercel, choose **Add New → Project**, import the GitHub repo.
3. Framework preset: **Other** (or leave auto-detected for static HTML).
4. Build command: none.
5. Output directory: `.`
6. Deploy.

## Important production upgrades
The cart is functional in-browser, but live payments, customer accounts, order tracking, inventory, admin authentication, image uploads and order management need a backend/database and payment provider before accepting real customer data or payments.

Replace the sample customer reviews and placeholder email with verified business details before launch.
